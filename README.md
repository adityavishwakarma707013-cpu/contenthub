# ContentHub CMS — React + Vite

## Run locally
1. Extract this ZIP.
2. Open the extracted `contenthub-react` folder in VS Code.
3. Open Terminal in that folder and run:

```powershell
npm install
npm run dev
```

4. Open the localhost URL shown by Vite (normally http://localhost:5173).

## Included
- React + Vite
- Admin dashboard, post CRUD, publish/unpublish, user management
- User signup/login, article browsing, search/filter, submissions, comments
- LocalStorage persistence and dark/light theme

## Note
This is a frontend academic demo. Authentication and passwords are stored in browser LocalStorage; do not use real credentials. For production, use a secure backend and password hashing.
